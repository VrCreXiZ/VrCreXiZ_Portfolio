## ✨ Key Features

- **🛡️ Custom Cyber Insignia & Dynamic Window Favicon**:
  - Bespoke geometric Slayer mark with concentric telemetry dials and neon blue runic accents.
  - Injected as the browser tab favicon and window header branding.
- **🌀 Modern Cyber Gate Preloader**:
  - High-tech entry portal with a central rotating holographic power core, concentric target reticles, and system diagnostic telemetry.
- **🎠 Magnetic Snap & Drag Project Carousel**:
  - Touch and mouse-draggable project showcase featuring infinite-style smooth auto-scroll, hover pause, and smart magnetic center-card snapping.
- **💻 Interactive Command Terminal & HUD**:
  - Developer console with custom commands (`help`, `projects`, `skills`, `contact`, `clear`) simulating an authentic UNIX workstation environment.
- **⚡ Tech Stack & Interactive Skill Matrix**:
  - Real-time filtered grid highlighting proficiency across Systems & Distributed Computing, Web Development, Backend Architecture, Databases, and Data Analytics.
- **🌓 Dual Blackboard / Cyber Aesthetics**:
  - Seamless Dark/Light theme switching with tailored contrast, blackboard textures, and subtle matrix grids.
- **📱 Fully Responsive**:
  - Optimized layout across mobile, tablet, desktop, and ultra-wide displays.
